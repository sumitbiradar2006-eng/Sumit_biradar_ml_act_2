Machine Learning Activity 2 – House Price Prediction using Linear Regression.

This project uses the California Housing Dataset from Scikit-learn to build a Linear Regression model and predict house prices. It includes data exploration, model training, testing, and evaluation using MAE, MSE, RMSE, and R² score.

**Technologies:** Python, Pandas, NumPy, Matplotlib, Scikit-learn.# Sumit_biradar_ml_act_2
